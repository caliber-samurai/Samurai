## Required Metadata

Every page must include:

- **Owner** (team or role accountable for accuracy)
- **Last Reviewed** date (`YYYY-MM-DD`)

## Content Standards

- Use clear, descriptive headings in a logical hierarchy.
- Keep language concise, unambiguous, and action-oriented.
- Prefer links over duplicated content when referencing source systems.

## Cross-Reference Expectations

Where applicable, include links to:

- Related systems
- Related repositories
- Related incidents
- Related change requests

## Review Cadence

- Operational and runbook content: review quarterly.
- Architecture and API references: review at least biannually.
- Governance and standards: review annually or upon policy change.
